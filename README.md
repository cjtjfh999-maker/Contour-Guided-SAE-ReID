# Contour-Guided Cross-Instance Reconstruction for Robust Person Re-identification

This repository is the official project page for our manuscript:

**Contour-Guided Cross-Instance Reconstruction for Robust Person Re-identification**

Submitted to *The Visual Computer*.

## Overview

This work studies robust person re-identification under background clutter, illumination variation, pose changes, and partial occlusion. The proposed framework introduces contour-guided cross-instance reconstruction as an auxiliary training objective for improving Transformer-based ReID representations.

## Code Availability

The original experimental code is currently being organized and verified. We plan to release the training and evaluation code, configuration files, and usage instructions after acceptance or once the implementation has been technically reconstructed and checked.

## Datasets

The experiments are conducted on public ReID benchmarks, including:

- Market-1501
- DukeMTMC-ReID
- MSMT17
- Occluded-Duke

Please refer to the original dataset providers for access and license requirements.
